features
[ LIVE ]
Real Chat Reader
Connects to actual Twitch IRC. Reads real messages as they happen, no login needed.
[ AI ]
Multi-LLM
Claude, GPT-4o, Gemini, Ollama, Hermes3, LLaMA, Mistral. Swap with one flag.
[ # ]
Keyword Triggers
Chat says "clip that" — clips the last 60 seconds instantly.
[ 9:16 ]
Auto Vertical Crop
One flag turns any clip into a TikTok/Reels/Shorts ready vertical video.
[ CC ]
Whisper Subtitles
Real timestamps burned in. 3 styles: TikTok, minimal, bold.
[ ▶ ]
Social Export
One-click send to YouTube, TikTok, Twitter/X, Discord.
[ OBS ]
OBS Plugin
Use OBS replay buffer instead of streamlink. Better quality.
[ ~ ]
Hype Detection
Tracks chat velocity, caps, emotes. Auto-clips spike moments.
[ ◈ ]
Live Dashboard
Real-time hype meter, chat feed, clip log in your terminal.
[ ♡ ]
Community
Shared prompt library. Upvote prompts. Browse clip gallery.
